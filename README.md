# 潜力股雷达 · A股多因子共振选股工具

基于 **8 大信号源做多因子共振分析** 的 A 股潜力股筛选工具，支持任意个股的实时多维研判。

> ⚠️ 本项目仅供学习与研究参考，**不构成任何投资建议**。股市有风险，入市需谨慎。

## 功能特性

### 1. 多因子共振选股（潜力股雷达）
用 8 类信号源做交叉验证，信号命中越多，趋势 + 资金 + 基本面同时看好的确定性越高：

| 信号源 | 说明 |
|---|---|
| 价值龙头 | 巴菲特式价值选股 |
| MACD 金叉 | 趋势反转信号 |
| 主力抢筹 | 大资金流入 |
| 业绩预增 | 业绩预告向好 |
| 高分评级 | 综合评分前列 |
| 资金 5 日流入 | 中期资金动向 |
| 高股息 | 分红回报 |
| 高盈利价值 | PB-ROE 匹配 |

- **信号热度雷达图**：可视化当前市场 8 类信号的覆盖强度
- **共振股榜单**：可按信号数 / 涨幅 / 市值 / PE 排序筛选
- **个股详情**：52 周价格区间、前瞻 PE、信号解读 + 风险提示

### 2. 个股速查（任意股票实时查询）
输入股票代码或名称，实时聚合多维度数据并自动生成研判：

- **代码/名称查询**：`600519`、`sh605006`、`贵州茅台` 均可，支持模糊联想
- **行情总览**：现价、PE/PB/股息率、换手/量比、5/10/20 日涨跌、52 周区间定位
- **技术信号 5 卡**：MACD、KDJ、RSI、BOLL、均线排列，每项带状态解读
- **资金动向 8 项**：今日/5日/10日/20日主力净流入 + 超大单/大单/中单/小单
- **筹码分布**：获利盘比例、平均成本、集中度
- **多因子三维研判**：量化面 + 资金面 + 位置面评分，自动生成风险提示

## 快速开始

```bash
# 1. 启动数据服务（端口 8890）
node server.js

# 2. 浏览器打开
open http://localhost:8890
```

页面内置 9 只共振股快照做兜底——即使服务未启动，也可直接打开 `潜力股雷达.html` 查询这 9 只股票。

## 项目结构

```
├── 潜力股雷达.html     # 主页面（选股雷达 + 个股速查）
├── server.js           # 本地数据服务（聚合行情/技术/资金/筹码数据）
├── index.html          # GitHub Pages 入口页
├── 山东玻纤股价监控.html # 个股监控看板示例
└── 山东玻纤趋势预测.html # 多因子趋势预测报告示例
```

## 数据说明

- 行情数据基于 A 股公开市场数据，随交易日更新
- 技术指标（MACD/KDJ/RSI/BOLL/MA）与资金流向为接口实时计算
- 榜单数据为构建时快照，实时性以实际查询为准

## 技术栈

- 纯前端 HTML + 原生 JS（零依赖，可直接打开）
- Node.js 本地数据服务（仅依赖 Node 内置模块）
- 红涨绿跌（中国股市配色惯例）
